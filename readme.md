# GitHub项目README｜基于AI Agent的FPGA工业缺陷检测系统

# AI\-Agent\-FPGA\-Defect\-Detection

## 📌 项目简介

本项目基于**AI Agent智能驱动架构**，实现轻量化缺陷检测算法的FPGA端部署，面向工业工件划痕、污渍、缺料等表面瑕疵检测场景。依托智能体自动化完成数据集处理、模型量化、硬件逻辑调试，解决传统FPGA开发调试繁琐、迭代周期长、嵌入式推理延迟高的痛点，实现低功耗、高速、高精度的工业视觉检测方案。

## ✨ 项目亮点

- **AI Agent赋能开发**：集成自动化调度智能体，完成数据清洗、模型剪枝、量化压缩、时序优化，大幅降低人工开发成本。

- **轻量化硬件部署**：对检测模型进行INT8定点量化，适配FPGA逻辑资源，搭建并行流水线推理架构。

- **高性能检测能力**：工业缺陷检测mAP可达95\.2%，毫秒级推理延迟，功耗远低于GPU方案。

- **高工程实用性**：适配工业流水线，支持实时图像采集、缺陷识别、结果输出。

## 🛠️ 技术栈

- 硬件平台：FPGA开发板

- 开发语言：Verilog、Python

- 智能框架：AI Agent自动化调度脚本

- 模型处理：模型轻量化、INT8量化、层融合优化

- 应用场景：工业表面缺陷检测、流水线质检

## 📊 项目成果

优化硬件加速逻辑与算法结构，相比传统开发方式，项目迭代周期缩短40%；FPGA端推理功耗降低90%，检测帧率显著提升，可稳定完成工业场景下的实时缺陷识别，具备良好的移植性与工程落地能力。
